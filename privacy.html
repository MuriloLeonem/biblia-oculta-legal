Política de Privacidade — Bíblia Oculta

Última atualização: 13 de outubro de 2026

O aplicativo Bíblia Oculta é uma ferramenta pessoal/desktop usada para publicar vídeos curtos (Shorts) de curiosidades bíblicas no TikTok, mediante autorização explícita do usuário.

1. Dados que coletamos

Ao conectar sua conta TikTok via OAuth, recebemos tokens de acesso necessários para publicar conteúdo em seu nome (por exemplo: access token, refresh token e open_id). Não coletamos senha da sua conta TikTok.

2. Como usamos os dados

  • Autenticar a conta TikTok autorizada
  • Enviar vídeos e legendas que você configurar localmente
  • Manter a sessão ativa (refresh do token) para publicações automáticas

3. Armazenamento

Os tokens ficam armazenados localmente no computador do usuário (arquivo de credenciais). Não vendemos nem compartilhamos dados com terceiros para fins publicitários.

4. Compartilhamento

Os dados de autenticação são usados apenas para comunicação com a API oficial do TikTok. Não há revenda de dados.

5. Seus direitos

Você pode revogar o acesso a qualquer momento em TikTok → Configurações → Segurança → Apps autorizados e apagar os arquivos locais de token.

6. Contato

Dúvidas sobre privacidade: entre em contato pelo e-mail da conta Google/TikTok associada ao canal Bíblia Oculta.
