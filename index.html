Bíblia Oculta

Ferramenta pessoal de desktop para publicar Shorts bíblicos no TikTok e no YouTube.

O que é: app local (PC) que gera e envia vídeos curtos de versículos, histórias e curiosidades das Escrituras — uso individual do dono da conta.

Canal: youtube.com/@biblialabs

Como funciona

  • Você autoriza o app uma vez via Login Kit do TikTok (OAuth).
  • Os tokens ficam só no seu computador.
  • O app sobe o MP4 pela Content Posting API (upload de arquivo local).
  • Não armazenamos senha da conta TikTok.
